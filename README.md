# 🤖 AI FAQ Chatbot

A simple and interactive FAQ Chatbot developed using Python and Streamlit as part of the CodeAlpha Artificial Intelligence Internship.

## 📌 Project Overview

The AI FAQ Chatbot allows users to ask frequently asked questions and receive instant answers through an interactive web interface.

Users can either select a question from the example questions or type their own question. The chatbot identifies supported questions and displays the relevant answer.

## ✨ Features

- 🤖 Interactive FAQ chatbot
- 💬 User question input
- 📋 Example questions dropdown
- ⚡ Instant answers
- ❓ Handles unknown questions
- 🎨 Clean and user-friendly Streamlit interface
- 📱 Simple and responsive layout

## 🛠️ Technologies Used

- Python
- Streamlit

## 🔄 How It Works

1. User selects an example question or enters a question.
2. The chatbot processes the entered question.
3. It checks the available FAQ knowledge base.
4. If a matching question is found, the chatbot displays the answer.
5. If no matching question is found, it asks the user to try another FAQ question.
